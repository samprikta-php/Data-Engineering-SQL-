Job Market Analytics: Exploratory Data Analysis Using SQL

🧾 Executive Summary (For Hiring Managers)
Project Scope: Developed three SQL-driven analytical queries to explore key trends in the data engineering job market.
Data Modeling: Leveraged multi-table joins across fact and dimension tables to extract meaningful business insights.
Analytics: Applied SQL aggregations, filtering, and sorting to identify the most in-demand, highest-paying, and most valuable technical skills.
Key Findings: Uncovered insights into SQL and Python demand, emerging cloud technologies, and salary trends to support data-driven career decisions.
Key SQL Files to Review

If you have limited time, start with these three queries:

01_top_demanded_skills.sql – Identifies the most in-demand skills based on job posting frequency.  
02_top_paying_skills.sql – Analyzes salary data to identify the highest-paying technical skills.  
03_optimal_skills.sql – Combines skill demand and salary insights to identify the most valuable skills for career growth.
