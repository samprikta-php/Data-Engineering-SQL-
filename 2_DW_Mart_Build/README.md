# Data Warehouse & Mart Build:Production ETL Pipleline
Built an end-to-end data engineering pipeline that ingests raw CSV files from Google Cloud Storage, transforms them into a star-schema data warehouse, and develops analytical data marts to support reporting and business insights.

🧾 Executive Summary (For Hiring Managers)
✅ Pipeline scope:  Built a complete data engineering pipeline to transform raw CSV files into a star-schema data warehouse and analytical data marts.<br/>
✅ Data modeling: Designed a star schema with fact tables, dimensions, and bridge tables for many-to-many relationships.
✅ ETL development:  Implemented robust Extract, Transform, Load (ETL) workflows with idempotent processing and data quality validation.
✅ Mart architecture: Developed specialized analytical data marts (Flat, Skills, and Priority) with additive measures and incremental update strategies to support efficient reporting and analysis.
